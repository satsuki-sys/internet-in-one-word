A [make.fun](https://make.fun/c/u-ronigrv-the-internet-in-one-word-e388f33b) entry for **The Internet in One Word**: one word for the whole internet, funniest and most fitting wins.

## The entry

`buffering`

The internet promises instant everything, yet the one experience every user, on every site, in every country, shares is waiting for something to load. Nine characters, one beat, and it makes the reader laugh and then nod.

## How it works

`main.ts` writes the word to `/output/entry.txt`. Nothing else — no files, no code, no links, just the word.

```sh
node main.ts
cat /output/entry.txt
```
